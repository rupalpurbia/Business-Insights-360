# Business Insights 360°

## Project Overview

This project focuses on analysing business performance across key areas such as finance, sales, marketing, supply chain and executive-level KPIs. The objective was to transform raw business data into a clear, interactive and insight-led Power BI dashboard.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
- Data Modelling

## Key Objectives

- Clean and transform raw business data
- Build a structured data model
- Create KPI-led dashboard pages
- Analyse business performance across multiple functions
- Present insights in a clear and decision-friendly format

## Dashboard Pages

- Finance View
- Sales View
- Marketing View
- Supply Chain View
- Executive View

## Key KPIs

- Net Sales
- Gross Margin
- Net Profit
- Forecast Accuracy
- Customer Performance
- Product Performance
- Market Performance

## Key Insights

- Identified high-performing and underperforming markets
- Compared actual performance against targets and previous periods
- Highlighted business areas requiring attention
- Improved visibility across finance, sales and operational metrics

## Outcome

The dashboard provides a consolidated view of business performance and supports faster, more informed decision-making through clear KPIs, interactive visuals and structured reporting.
