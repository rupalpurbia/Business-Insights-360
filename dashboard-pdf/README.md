# Dashboard PDF

This folder contains the PDF version of the Business 360 Power BI dashboard.

The PDF export provides a static view of the dashboard pages for quick review, while the interactive Power BI link is available separately in the `interactive-dashboard-link` folder.

## Included Dashboard Pages

- Finance View
- Sales View
- Marketing View
- Supply Chain View
- Executive View

## Purpose

The PDF version is included to give viewers a quick, accessible snapshot of the dashboard layout, KPI structure, visual design and page-level analysis without requiring access to the interactive report.

## Note

The interactive dashboard link should be used for full exploration of filters, slicers and drill-through functionality.
