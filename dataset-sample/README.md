# Dataset Information

The original dataset used for this Business 360 Power BI dashboard is not included in this repository due to file size, confidentiality and data-sharing restrictions.

## Data Source Overview

The project was built using data from multiple sources. The primary data source was a SQL database, supported by additional Excel files used for lookup, reference and supplementary business information.

## Source Types

- SQL database connection as the main data source
- Excel files for supporting lookup and reference tables
- Multiple business tables related to sales, finance, products, customers, markets and supply chain performance

## Data Connection Approach

A SQL connection was created in Power BI to import and model the main business data. Supporting Excel files were also loaded and transformed using Power Query.

The data was then cleaned, standardised and prepared for reporting before being used in the Power BI data model.

## Data Preparation Summary

Key preparation steps included:

- Connecting Power BI to the SQL data source
- Importing supporting Excel files
- Reviewing table structure and relationships
- Correcting data types
- Standardising date and fiscal period fields
- Removing invalid or blank records
- Creating calculated columns where required
- Merging supporting lookup tables
- Building clean fact and dimension tables
- Preparing the dataset for Power BI modelling and dashboard development

## Dataset Coverage

The dataset supported analysis across the following business areas:

- Finance performance
- Sales performance
- Marketing performance
- Supply chain performance
- Executive-level business KPIs
- Customer performance
- Product and segment performance
- Market and regional performance
- Forecast accuracy and net error analysis

## Note

No raw or original dataset files are uploaded in this repository. The repository instead includes dashboard screenshots, DAX measures, Power Query cleaning steps, business insights and an interactive dashboard link to demonstrate the project approach and analytical outcome.
